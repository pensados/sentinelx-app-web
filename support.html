Support

Need help with SentinelX, hit a bug, or have a question about setup? Here's how to reach us.

Report a bug or request a feature

The fastest way to reach us about the agent, installer, or protocol is a GitHub issue. It helps to include your OS (Linux or macOS), the agent version (the capabilities op reports it), and steps to reproduce.

github.com/pensados/sentinelx-cloud-core/issues

Questions and discussion

For setup help, usage questions, or ideas, GitHub Discussions is a good place — and answers there help other users too.

github.com/pensados/sentinelx-cloud-core/discussions

Email

Prefer email? Write to sentinelx@pensa.ar. For account questions or data-deletion requests, see the Privacy Policy.

Getting started

New to SentinelX? Install the open-source agent with one command on any Linux or macOS host — it auto-detects your OS:

curl -fsSL https://get.sentinelx.app | bash

Then add SentinelX as an MCP connector in your LLM. Full details are on the home page.

Security issues

Found a security vulnerability? Please report it privately to sentinelx@pensa.ar rather than opening a public issue, and we'll respond as quickly as we can.

Response times

SentinelX is maintained by a small team, and its agent is open source. We aim to reply within a few business days. Public GitHub issues and discussions often get the fastest input.
